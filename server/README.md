# Sistema de Control de Inventario - Hospital Regional de Huehuetenango

Sistema web para la gestión de equipos médicos y mobiliario del Hospital Regional de Huehuetenango "Dr. Jorge Vides Molina".

## 📋 Descripción

Sistema desarrollado como proyecto de tesis de Ingeniería en Sistemas para digitalizar y optimizar el control de inventario de equipos médicos y mobiliario del hospital, reemplazando procesos manuales con una solución moderna basada en web.

## 🎯 Características Principales

- ✅ Gestión completa de equipos médicos y mobiliario
- ✅ Sistema de traslados entre áreas con "conocimientos" digitales
- ✅ Proceso de bajas con dictamen de Mantenimiento
- ✅ Generación de reportes (Tarjetas de Responsabilidad, Reporte Anual)
- ✅ Códigos QR para identificación rápida
- ✅ Aplicación web instalable (PWA) para escaneo móvil
- ✅ Control de acceso basado en roles
- ✅ Auditoría completa de operaciones

## 🛠️ Tecnologías

### Backend
- Node.js 22 LTS
- Fastify (Framework web)
- SQLite + Drizzle ORM
- TypeScript

### Frontend
- React 19
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
